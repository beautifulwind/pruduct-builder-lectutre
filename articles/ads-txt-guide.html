ads.txt 완벽 가이드: 의미, 작성법, 위치

글: beautifulwind · 2026년 10월 29일 · 사이트 운영

광고를 게재하는 사이트라면 ads.txt라는 작은 텍스트 파일 하나를 반드시 챙겨야 합니다. 이 파일이 무엇을 막아 주는지, 각 항목이 무슨 뜻인지, 그리고 정적 사이트에서 흔히 놓치는 위치 문제까지 정리했습니다.

ads.txt는 왜 필요한가

디지털 광고는 사이트 운영자와 광고주 사이에 여러 중개 플랫폼이 끼어 거래됩니다. 이 과정에서 누군가 유명 사이트인 것처럼 꾸며 광고 지면을 판매하는 도메인 위장(spoofing)이 문제가 되었습니다. ads.txt(Authorized Digital Sellers)는 IAB Tech Lab이 만든 표준으로, 사이트 운영자가 "내 사이트의 광고 지면은 이 판매자들만 팔 수 있다"고 공개적으로 선언하는 파일입니다. 광고 구매자는 이 파일을 확인해 허가받지 않은 판매자의 지면을 걸러냅니다.

운영자 입장에서는 내 사이트 이름을 도용한 가짜 지면에 광고비가 새어 나가는 것을 막아 주므로, 결과적으로 내 지면의 신뢰도와 수익을 지키는 장치입니다.

한 줄의 의미

Google AdSense를 사용한다면 보통 다음과 같은 한 줄이면 충분합니다.

google.com, pub-0000000000000000, DIRECT, f08c47fec0942fa0
순서항목설명
1광고 시스템 도메인지면을 판매하는 플랫폼의 도메인. AdSense는 google.com입니다.
2게시자 ID그 플랫폼에서의 내 계정 ID. AdSense 화면의 pub-로 시작하는 숫자입니다. 광고 코드의 ca-pub-에서 ca-를 뺀 값과 같습니다.
3관계내가 직접 계정을 관리하면 DIRECT, 다른 회사가 대신 판매하면 RESELLER입니다.
4인증 기관 ID선택 항목으로, 광고 시스템을 식별하는 TAG ID입니다. Google의 값은 f08c47fec0942fa0입니다.

여러 광고 네트워크를 함께 쓴다면 네트워크마다 한 줄씩 추가합니다. # 뒤에 쓴 내용은 주석으로 처리됩니다.

어디에 두어야 하나

ads.txt에서 가장 중요한 규칙은 위치입니다. 파일은 반드시 도메인의 최상위, 즉 https://example.com/ads.txt에서 열려야 합니다. 하위 폴더에 있는 파일은 표준상 인식되지 않습니다.

이 규칙 때문에 GitHub Pages의 프로젝트 사이트처럼 사용자이름.github.io/저장소이름/ 아래에서 운영되는 사이트는 저장소에 ads.txt를 넣어도 /저장소이름/ads.txt에 위치하게 되어 인정받지 못합니다. 해결 방법은 두 가지입니다.

  • 사이트에 사용자 지정 도메인을 연결해 사이트 자체를 도메인 최상위로 옮깁니다. 가장 권장되는 방법입니다.
  • 도메인 최상위를 담당하는 저장소(사용자이름.github.io)에 ads.txt를 둡니다.

또한 광고 신청 시 등록하는 사이트 주소도 하위 경로가 아닌 도메인 단위인 경우가 대부분이므로, 수익화를 계획하고 있다면 도메인 연결을 먼저 해 두는 것이 좋습니다. 배포 방법은 GitHub Pages 배포 가이드의 사용자 지정 도메인 부분을 참고하세요.

확인하는 방법

  1. 브라우저에서 https://내도메인/ads.txt를 직접 열어 내용이 그대로 보이는지 확인합니다. HTML 페이지나 404가 보이면 위치가 잘못된 것입니다.
  2. www가 붙은 주소와 붙지 않은 주소 중 실제 사이트 주소에서 열리는지 확인합니다. 한쪽이 다른 쪽으로 리디렉션되는 것은 괜찮습니다.
  3. AdSense를 쓴다면 계정의 사이트 메뉴에서 ads.txt 상태를 확인할 수 있습니다. 파일을 올린 뒤 반영되기까지 며칠이 걸릴 수 있습니다.

자주 하는 실수

  • 게시자 ID에 ca-를 붙이는 경우: ads.txt에는 pub-로 시작하는 값만 씁니다.
  • 파일 이름 오타: ads.txt는 소문자여야 하며 ad.txt, ads.txt.txt는 인식되지 않습니다.
  • 워드프로세서로 작성: 일반 텍스트 편집기로 저장해야 보이지 않는 서식 문자가 섞이지 않습니다.
  • 쓰지 않는 네트워크를 남겨 두는 경우: 계약이 끝난 판매자는 지워야 파일이 선언하는 의미가 정확해집니다.

정리

ads.txt는 내용은 한 줄이지만, 위치가 틀리면 아무 효과가 없습니다. 도메인 최상위에서 열리는지, 게시자 ID가 정확한지 두 가지만 확인하면 대부분의 문제를 피할 수 있습니다.
